# 모든 템플릿 공통

> 템플릿의 **섹션 구성은 새 문서 전용**이다. 변환 문서는 원본의 목차·소제목을 그대로 쓰고(`conversion-rules.md`), 템플릿에서는 frontmatter와 `**요약**` 한 줄만 가져온다. 분량 상한도 변환 문서에는 경고로만 적용된다.

## frontmatter (필수)
`references/naming-and-links.md` 의 형식을 따른다. 상태 헤더는 본문에 쓰지 않는다 (위키 반영 때 자동 생성).

## 본문 첫 줄 (필수)
```markdown
**요약** 이 문서가 무엇을 정하는지 1~2문장.
```
변환 문서는 요약을 **추가**하고 원문은 그대로 둔다.

## 분량 측정
- 줄 = frontmatter 제외, 빈 줄 제외, 코드 블록·표 포함
- 섹션 = `##` 개수 (`<details>` 안 변경 이력은 제외)
- 새 문서가 넘치면 줄이지 말고 `appendix.md` 로 옮긴다. 그래도 넘치면 `limit_exempt` 에 사유
- 변환 문서(`sources:` 있음)는 상한 초과가 경고다. 부록으로 보내지 않고 긴 블록을 제자리에서 접는다

## 변경 이력 (선택, 문서 끝)
결정이 바뀐 것만, 최대 5줄.
```markdown
<details><summary>변경 이력</summary>

- 09-16 긴 추천 이유를 ③ 응답에 포함 → [결정 로그](../../dec/000-decision-log.md)
</details>
```

## 공통 금지
- 없는 문서에 링크 걸기 → `ERD (작성 예정)`
- 다른 파트 요구사항을 본문에만 쓰기 → 결정 로그에도 한 줄
- 같은 내용 복사 → 원본 문서에 링크
