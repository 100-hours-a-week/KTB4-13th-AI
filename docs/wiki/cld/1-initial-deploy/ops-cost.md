**요약** 배포 주기 3주, 장애 허용 수준(중단은 허용·데이터 유실은 불허)을 정의하고, 3주 POC 기준 인프라 비용을 계산한다.

## 1. 배포 빈도

사용자는 단순한 기능 제공보다 개인 취향에 맞는 추천 정확도와 납득 가능한 추천 결과를 안정적으로 제공받는 것이 더 중요하다.

하나의 기능 단위가 완성되고 추천 품질과 주요 사용자 흐름을 함께 검증한 후 배포하는 방식을 적용한다.

따라서 V1 개발 및 배포 기간은 약 **3주**로 설정한다.

## 2. 장애 허용 수준

V1은 3주간 운영되는 초기 POC이고 비용이 우선이므로 높은 가용성은 요구하지 않는다.

따라서 **일시적인 서비스 중단은 허용하되, 주문·거래 데이터 유실은 허용하지 않는 수준**으로 설정한다.

현재 인프라는 역할별 단일 VM 2대로 구성된다.

- 애플리케이션 VM: Nginx, React, Spring Boot, MySQL
- AI VM: AI 임베딩 서버, Vector DB

각 VM의 가용성은 약 99.5%로 가정한다.

- 애플리케이션 및 핵심 기능 가용성: 약 **99.5%**
- 월간 환산 중단 시간: 약 **216분**
- 추천 기능 가용성: `99.5% × 99.5% = 약 99.0%`
- 추천 기능의 월간 환산 중단 시간: 약 **431분**

서비스의 주요 이용 시간은 점심과 저녁을 포함한 하루 6시간이다.

장애가 주요 이용 시간과 겹치는 비율은 `6시간 ÷ 24시간`으로 계산한다.

- 핵심 서비스 중단 시간: `216분 × 6 ÷ 24 = 약 54분`
- 추천 기능 중단 시간: `431분 × 6 ÷ 24 = 약 108분`
- 핵심 서비스 영향 사용자: `36명 × 54분 ÷ 360분 = 약 5.4명`
- 추천 기능 영향 사용자: `36명 × 108분 ÷ 360분 = 약 10.8명`

3주 POC 기간으로 환산하면 다음과 같다.

- 핵심 서비스 전체 중단 시간: 약 **151분**
- 주요 이용 시간과 겹치는 핵심 서비스 중단 시간: 약 **38분**
- 추천 기능 전체 중단 시간: 약 **302분**
- 주요 이용 시간과 겹치는 추천 기능 중단 시간: 약 **75분**

초기 POC에서는 제한적인 사용자 영향보다 서버 이중화를 생략하여 얻는 비용 절감 효과가 더 크다고 판단한다.

따라서 각 역할을 단일 VM으로 운영하고 일시적인 서비스 중단과 추천 기능 제한을 허용한다.

단, MySQL 데이터는 별도로 백업하고 Vector DB와 임베딩 데이터는 원본 데이터를 기준으로 재생성할 수 있도록 구성한다.

## 3. 예상 인프라 비용

### 운영 조건

- AWS 서울 리전 사용
- `t3.small` EC2 2대 24시간 운영
- EBS gp3 30GB × 2 사용
- React Frontend는 S3 + CloudFront로 배포
- 운영 기간: 3주
- 적용 환율: $1당 1,400원

### 예상 비용

| 항목 | 월 예상 비용 | 3주 예상 비용 |
|---|---:|---:|
| `t3.small` × 2 | $37.96 | $26.21 |
| Public IPv4 × 2 | 약 $7.30 | 약 $5.04 |
| EBS gp3 60GB | 약 $5.47 | 약 $3.83 |
| Route 53 | 약 $0.50 | 약 $0.35 |
| S3 | $1 미만 | $1 미만 |
| CloudFront | 초기 트래픽 기준 매우 낮음 | 매우 낮음 |
| 백업·스냅샷 | 약 $1~3 | 약 $0.70~2.10 |
| CloudWatch·데이터 전송 | 초기 사용량 기준 소액 | 소액 |

예상 월 비용은 약 **$53~56**, 원화로 약 **7.4~7.8만 원**이다.

CPU 추가 사용, 데이터 전송, 백업 및 부가세에 따른 변동 가능성을 고려하여 실제 예산은 월 약 **9만 원**으로 설정한다.

### 크레딧 적용

3주 POC 비용은 AWS 기본 $100 크레딧 안에서 충당할 수 있을 것으로 예상한다.

| 운영 기간 | 적용 크레딧 | 예상 실제 결제액 |
|---|---:|---:|
| 3주 | 기본 $100 | 약 $0 |
| 3주 | 최대 $200 | 약 $0 |
| 1개월 | 기본 $100 | 약 $0 |
| 1개월 | 최대 $200 | 약 $0 |

따라서 3주 POC의 실제 결제 예상액은 약 **$0**이며, 크레딧 소진 이후에는 월 약 **7~9만 원**의 인프라 비용이 발생할 것으로 예상한다.
