**요약** 회원가입부터 주문·취소·구매확정·후기·포인트까지 서비스가 지켜야 할 공통 비즈니스 정책과 원본 체크리스트 126개 대응표를 담은 최종본이다.

이 문서는 회원가입부터 주문, 취소, 구매확정, 후기와 포인트까지 서비스가 지켜야 할 규칙을 정리한다. 기존 분석의 추정이나 중간 제안보다 이후에 명시적으로 변경·확정한 결정을 우선한다. 구현 완료나 실제 서비스 운영 검증을 의미하지 않는다.

### 문서 상태와 사용 방법

| 구분 | 상태 | 사용 방법 |
|---|---|---|
| 서비스의 공통 비즈니스 정책 | **최종본** | 설계·개발·팀 논의의 정책 기준으로 사용한다. 이후 변경은 변경 기록에 남긴다. |
| 쿠폰·상품·온보딩 콘텐츠별 값 | 운영 시 입력 | [운영값 목록](#operating-values)에 따라 개별 콘텐츠를 등록한다 ¹ |
| 개인정보 수집·이용 안내 및 서비스 조건 문안 | **내부 검토 초안** | 실제 문의 창구·수집 항목·외부 업체와 처리 근거를 확인하기 전 게시하거나 동의를 받는 용도로 사용하지 않는다. |
| 실제 서비스 동작·법률 검토 | 별도 검증 대상 | 정책 문서의 완성과 구현·공개 운영의 검증을 구분한다. |

¹ 공통 정책을 다시 결정할 필요는 없다.

현재 정책 정의 단계는 이 최종본으로 마무리한다. 개인정보 안내의 실제 운영 사실 확인은 [공개 전 점검표](#privacy-drafts)로 이관한다. 이 조건을 임의의 값으로 채워 전체 서비스가 출시 준비를 마쳤다고 표시하지 않는다.

## 1. 목적·범위·용어

### 적용 범위

- 결제는 테스트로 운영하되 구매확정, 구매·후기 포인트 지급, 부분취소·환불까지 포함한다.
- 실제 배송·상품 회수·정산은 제외한다. 배송비는 0원이다. 별도 반품 신청·승인 절차 없이 미확정 상품의 취소·환불로 처리한다.
- 구매확정 이후 일반 취소와 예외 환불은 모두 이번 MVP에서 제공하지 않는다. 이는 테스트 서비스의 기능 범위이며 실제 판매에서 법정 권리를 배제한다는 뜻이 아니다.
- 블록체인 기반 화폐·토큰은 제외한다. 이 문서의 포인트와 서로 다른 개념이다.
- 코드, 변수·클래스·상태 값, 저장 구조, API 구조, 외부 PG 연동·장애 대응은 정의하지 않는다. 기존 분석의 해당 질문은 추적용으로만 남긴다.
- 기존 검토 초안과 외부 명세·ERD는 수정하지 않는다. 실제 판매 전환 및 기술 설계는 별도 작업이다.

### 용어와 결정의 성격

- **주문상품**: 한 주문 안의 동일 상품과 그 구매 수량을 묶은 단위. 책 A 3권은 하나의 주문상품이다.
- **일반 결제금액**: 상품 할인·쿠폰·사용 포인트를 차감하고 남은 원화 결제금액. MVP에서는 테스트 결제한다.
- **쿠폰**: 특정 상품의 가격을 할인하는 혜택. 현금이나 포인트로 반환하지 않는다.
- **포인트**: 구매·후기 보상으로 지급하는 혜택. 결제 사용 가치는 1포인트당 1원이다. 일반 충전·현금 출금·양도는 제공하지 않는다.
- **구매확정**: 구매를 확정하여 해당 주문상품의 일반 취소를 종료하는 사용자 행동 또는 자동 처리. 결제 완료와 구분한다.
- **탈퇴 신청 / 완료**: 신청 후 7일은 복구 가능 기간이다. 그 기간이 끝나면 탈퇴가 완료된다.

본문의 ‘확정’은 사용자 결정 또는 사용자가 일괄 채택한 기본안이다. 계산 예시는 확정 규칙을 설명하기 위한 가정이며 상품·쿠폰 운영값을 새로 지정하지 않는다. 캠페인별 할인율·한도·기간, 온보딩 질문별 선택 개수는 해당 콘텐츠에 명시하는 운영값이며 공통 수치를 임의로 만들지 않는다.

### 공통 기간 계산 기준

다음은 남은 세부 기준 정리 요청에 따라 채택한 문서 기준이다. 모든 사용자 안내는 한국 표준시(Asia/Seoul, UTC+9)를 사용한다.

- 15분은 시작 시각에서 15분, 7일·90일은 각각 24시간의 7배·90배가 경과한 시점이다. 자정이나 해당 날짜의 영업 종료로 늘리지 않는다.
- 1년은 다음 해 같은 월·일·시각까지다. 2월 29일처럼 다음 해에 같은 날짜가 없으면 2월 28일 같은 시각을 종료로 삼는다. 일괄 365일로 바꾸지 않는다.
- 혜택 사용·탈퇴 취소는 종료 시각 **전까지** 가능하고, 정확히 종료 시각부터 만료·탈퇴 완료 대상이다. 자동 구매확정과 보존기간 종료는 그 시각 **이후부터** 적용한다.
- 쿠폰의 시작·종료일시는 발급 안내에 명시한다. 포인트는 적립 시각, 주문은 최초 생성 시각, 자동확정은 결제 완료 시각, 탈퇴 취소는 신청 시각, 혜택 수령 이력 1년은 최종 탈퇴 완료 시각을 기준으로 한다.
- 서비스 귀책 보상 7일은 실제 보상 지급 시각부터 계산한다. 보상 사용기간 7일을 원래 혜택의 유효기간에 덧붙이지 않는다.
- 자동확정 1일 전과 포인트 만료 7일 전 알림은 위 종료 시점에서 해당 기간을 거슬러 계산한다. 기존에 같은 날 만료분을 묶어 알리는 정책은 유지하되 각 혜택의 정확한 종료일시를 확인할 수 있어야 한다. 알림 지연이 사용기간을 연장하지 않는다.

| 시작·조건 | 종료·처리 예시 |
|---|---|
| 2026-09-09 10:00에 주문 생성 | 10:15부터 재결제 불가 |
| 2026-09-09 10:00에 결제 완료 | 2026-09-16 10:00부터 자동확정 대상. 취소 처리 중이면 기존 보류 규칙 적용 |
| 2028-02-29 10:00에 포인트 적립 | 2029-02-28 10:00부터 만료 |
| 2027-03-01 10:00에 포인트 적립 | 2028-03-01 10:00부터 만료. 윤일 때문에 366일이지만 달력상 1년 |

기간 경계와 취소가 겹쳐도 같은 상품을 확정과 취소로 중복 처리하지 않는다. 기술적인 처리 순서는 구현 설계에서 정한다.

## 2. 도메인별 정책

<a id="member"></a>
### 2.1 회원·로그인·탈퇴

관련 기존 정책: USR-001~004, SEC-001, RET-001.

- 이메일 제공이 가능한 것으로 사전 검수한 소셜 서비스만 지원한다. 제공자가 전달한 이메일을 별도 이메일 인증 없이 사용한다.
- 이메일이 누락되면 계정을 만들지 않고 제공 동의 확인·재시도를 안내한다.
- 기존 회원과 같은 이메일의 다른 소셜 계정은 자동 연결하거나 중복 가입시키지 않는다. 기존 로그인 수단을 안내한다. 추가 소셜 연결은 제공하지 않는다.
- 이메일이 다르면 동일인 여부를 판별하지 않는다. 이메일 기준 정책을 본인인증이나 우회 가입의 완전한 차단으로 표현하지 않는다.
- 사용자는 본인 주문·배송지·포인트·후기만 변경할 수 있다. 다른 회원의 자산이나 거래를 이용할 수 없다.
- 진행 중 거래가 있으면 종료 후 탈퇴한다. 미결제 주문은 취소하고, 취소·환불 처리 중이거나 미확정 상품이 남아 있으면 탈퇴를 제한한다.
- 포인트가 음수이면 이후 적립으로 충당하거나 부족분만 1포인트당 1원으로 납부해 0으로 만든 뒤 탈퇴한다. 부족분 납부는 일반 충전·상품 구매·구매 적립 대상이 아니다. 테스트 MVP에 실제 금전 수납을 도입했다는 의미는 아니다.
- 탈퇴 신청 후 7일 이내에 다시 로그인하면 탈퇴를 취소하고 기존 계정을 복구한다. 쿠폰·포인트의 원래 유효기간은 계속 흐르므로 이미 만료된 혜택은 복구하지 않는다.
- 7일 경과 후 탈퇴가 완료되면 남은 혜택은 소멸하고 기존 계정은 복구하지 않는다. 재가입은 즉시 가능하며 추가 30일 제한은 없다. 재가입 계정에 이전 주문·혜택을 복원하지 않는다.
- 신규 혜택 수령 이력은 최종 탈퇴 후 1년간 이메일 기준으로 확인하여 재지급을 막는다. 기간 종료 후 이력을 파기하므로 영구 중복 차단이 아니다. [보존 정책](#retention)을 함께 적용한다.

<a id="onboarding"></a>
### 2.2 온보딩·취향

관련 기존 정책: ONB-001~006.

- 온보딩은 필수다. 완료 전에는 온보딩 화면만 이용할 수 있고 상품 탐색·구매로 건너뛸 수 없다.
- 노출된 모든 질문에 답하고 질문별 최소·최대 선택 조건을 충족해야 완료된다. 선택 조건은 각 질문에 표시한다.
- 최초 입력만 허용하며 완료 후 답변 수정·온보딩 재수행은 제공하지 않는다. 진행 중 답변 선택과 완료 후 변경을 구분한다.
- 온보딩 답변은 회원 이용 중 유지한다. 탈퇴 완료 시 답변과 개인화 정보를 삭제한다.
- 질문 문구, 질문별 실제 선택 개수, 선택 도서 목록은 콘텐츠 운영 범위다. 기존 자료의 불일치를 근거로 임의의 공통 최소·최대값을 정하지 않는다.

<a id="product"></a>
### 2.3 상품·가격·재고

관련 기존 정책: PRD-001~002, INV-001, MON-001.

- 판매가와 할인가를 구분한다. 유효한 상품 할인이 있으면 할인가를, 없으면 판매가를 쿠폰 적용 전 단가로 사용한다. 이미 반영한 상품 할인을 다시 차감하지 않는다.
- 장바구니에는 현재 구매가격을 표시한다. 주문 생성 때 적용 단가를 확정하고 주문의 15분 유효기간 동안 유지한다.
- 장바구니에서 보던 가격과 주문할 가격이 달라지면 변경 금액을 확인할 수 있게 안내한다.
- 같은 상품은 한 주문에서 1~500개까지 구매 가능하며 실제 확보 가능한 재고를 넘을 수 없다.
- 주문 생성 시 필요한 재고를 확보한다. 마지막 재고를 중복 판매하지 않는다. 부족하면 수량을 임의로 줄이지 않고 변경을 안내한다.
- 판매가 허용되고 확보 가능한 재고가 있으면 구매 가능하다. 재고가 없으면 품절, 운영자가 판매를 막은 상품은 판매 중지로 안내한다.
- 미결제 주문 종료·취소 시 확보 재고를 반환한다. 결제 후에는 취소·환불 완료 수량을 반환한다. 운영자가 판매 중지한 상품은 재고가 돌아와도 판매 중지를 유지한다.
- 결제 실패 후 같은 주문을 다시 결제하더라도 구매 가능 여부와 필요한 재고를 재확인한다. 과거 재고 확보만으로 재결제를 보장하지 않는다.
- 도서 외 상품 확대나 서지정보 누락 상품의 등록 조건은 이번 위키에서 신규 기능으로 정의하지 않는다.

<a id="cart"></a>
### 2.4 장바구니

관련 기존 정책: CRT-001~004.

- 회원당 장바구니 하나를 사용한다. 같은 상품을 다시 담으면 기존 수량에 합산한다.
- 수량을 별도로 선택하지 않으면 1개로 담는다. 상품별 최대 수량은 500개다.
- 품절·판매 중지 상품은 상태 표시와 함께 남겨두되 주문 선택은 막는다. 사용자는 직접 삭제할 수 있다.
- 일부 상품·수량을 선택하여 주문할 수 있다.
- 결제 완료 시 주문한 수량만 제거한다. 실패·미결제 때는 남겨두고 주문 후 추가로 담은 수량은 보존한다. 사용자가 그 사이 직접 삭제·변경한 경우에도 장바구니 수량을 음수로 만들거나 상품을 임의로 다시 추가하지 않는다.

<a id="order"></a>
### 2.5 주문·결제

관련 기존 정책: ORD-001~005, PAY-001~004, SYS-001.

- 한 주문에 여러 주문상품을 포함할 수 있다. 주문에는 구매 당시 상품 설명에 필요한 상품명, 단가, 수량, 할인·포인트·최종 금액과 주문 당시 배송지 내용을 남겨 과거 구매 내용을 확인할 수 있게 한다. 보존 종료 시에는 별도 파기 규칙을 따른다.
- 주문은 최초 생성부터 15분간 유효하다. 실패·중단·재시도로 기한을 연장하지 않는다. 기한이 끝난 미결제 주문은 종료하고 새 주문에서 가격·혜택·구매 가능 여부를 다시 판단한다.
- 명확한 결제 실패나 사용자 중단만으로 주문 자체를 즉시 폐기하지 않는다. 기한 내 동일 주문 재결제를 허용한다. 이미 취소·만료된 주문은 다시 결제할 수 없다.
- 재결제 전 원래 상품 단가를 유지하되 쿠폰·포인트의 현재 유효성, 사용 가능량, 상품 판매 가능 여부와 재고를 다시 확인한다.
- 혜택이 달라지면 새 최종 금액을 안내하고 사용자가 확인한 뒤 결제한다. 사용자 확인 금액과 실제 주문 금액이 다르면 그대로 결제하지 않는다.
- 결제에 쓰려던 쿠폰·포인트는 결제 실패가 명확해지면 다시 사용할 수 있게 한다. 이미 만료된 경우와 서비스 사유의 예외는 [혜택 복구](#benefit-exception)를 따른다. 임의의 추가 잠금 시간을 두지 않는다.
- 쿠폰·포인트의 유효기간은 결제 대기로 늘어나지 않는다. 원래 만료 전에 결제가 완료되어야 사용을 인정한다.
- 수량·배송지·쿠폰·사용 포인트를 사용자가 바꾸려면 기존 주문을 취소하고 새로 주문한다. 재결제 시 만료 혜택 재검증은 사용자 임의의 주문 편집과 구분한다.
- 결제 완료는 구매확정이 아니다. 결제 완료 후에도 구매확정 전 취소 가능한 기간을 둔다.
- 동일 결제로 구매 대금·혜택을 중복 차감하거나 동일 취소로 중복 환불하지 않는다. 기술적인 보장 방법은 제외한다.
- 결제 완료 후 결제수단만 바꾸는 기능은 제공 범위에 포함하지 않는다. 외부 결제수단별 지원·제약은 이 위키에서 정하지 않는다.

<a id="confirmation"></a>
### 2.6 구매확정

관련 기존 정책: ORD-003, ORD-004, CAN-002, PNT-003, REV-003.

- 결제 완료 후 사용자가 주문상품별로 직접 구매확정할 수 있다. 직접 확정하면 즉시 확정되고 취소 제한·구매 적립이 적용된다.
- 같은 책 3개가 하나의 주문상품이라면 남은 수량 전체를 함께 확정한다. 1개 취소 후 남은 2개 확정은 가능하지만 그중 1개만 확정하지는 않는다.
- 결제 완료 후 7일에 남은 미확정 주문상품을 자동확정한다. 상품마다 결제 완료 기준으로 계산하며 부분취소로 기한을 새로 시작하지 않는다.
- 같은 주문상품의 일부 수량이 취소 처리 중이면 직접·자동 구매확정을 보류한다. 취소·할인 재계산 완료 후 남은 수량을 확정할 수 있다. 원래 기한이 지났으면 처리 완료 후 남은 수량을 자동확정한다.
- 한 주문 안에서 확정 상품·취소 상품·미확정 상품이 함께 존재할 수 있다. 확정 상품 때문에 다른 미확정 상품의 취소를 막지 않는다.
- 구매확정된 주문상품은 일반 취소·환불할 수 없다. 구매확정 후 운영자 예외 환불도 MVP에서 제외한다.
- 주문 내역에 예정일과 확정 후 취소 제한을 표시하고 1일 전 미확정 상품에 서비스 내 알림을 보낸다. 직접 확정 전에도 취소 불가를 안내한다.

<a id="cancel"></a>
### 2.7 취소·환불

관련 기존 정책: CAN-001~005, CPN-006, PNT-001.

- 미결제 주문 취소, 결제 완료 후 미확정 상품 전체취소·일부 상품 취소·일부 수량 취소를 지원한다. 별도 반품 개념은 두지 않는다.
- 취소 가능한 남은 수량 안에서 여러 번 취소할 수 있다. 이미 취소한 수량과 구매확정한 상품은 다시 취소하지 않는다.
- 취소·환불이 진행 중인 수량은 구매확정을 막는다. 완료되지 않았는데 환불 완료로 안내하거나 재고·혜택을 중복 복구하지 않는다. 기술적 실패 처리·재시도 절차는 범위 밖이다.
- 포인트는 주문 당시 상품·수량별 배분액을 기준으로 반환하고 남은 수량에 다시 배분하지 않는다. 반환 시 이미 만료된 사용분은 복구하지 않는다.
- 쿠폰은 남은 수량의 구매금액으로 원래 할인 조건을 다시 심사한다. 정액·정률·최대 할인 한도와 최소금액을 같은 기준으로 재계산한다. 현재 새로 바뀐 판매가나 새 쿠폰 조건을 과거 거래에 적용하지 않는다.
- 쿠폰 할인 감소분은 일반 결제 환불액에 반영한다. 포인트 반환액을 할인 회수 명목으로 임의 차감하지 않는다.
- 일반 결제 환불액이 음수가 되는 부분취소는 제한하고 쿠폰 적용 주문상품의 남은 수량 전체취소를 안내한다. 추가 결제를 받아 부분취소하지 않는다.
- 확정된 금액 보존 경계 규칙: 재계산한 남은 상품의 쿠폰 차감 후 금액이 유지할 포인트보다 작아지거나, 계산 환불액이 남은 일반 결제액을 초과하는 부분취소도 같은 방식으로 제한한다. 포인트 고정 배분과 결제액 초과 환불 금지를 동시에 지키기 위한 처리다.
- 반복 부분취소 뒤 전체취소는 최초 원금을 다시 지급하는 것이 아니라 남아 있는 미환불 일반 결제액과 미반환 포인트만 처리한다. 할인 회수액을 여러 번 중복 차감하지 않는다.
- 쿠폰 적용 상품 전량 취소 완료 시 원래 유효기간이 남은 쿠폰만 다시 사용할 수 있게 한다. 일부 수량 취소는 쿠폰을 복구하지 않는다. 나눠 취소하여 최종 전량 취소된 경우도 같은 기준이다.

<a id="address"></a>
### 2.8 배송지

관련 기존 정책: ADR-001~004.

- 첫 배송지는 자동으로 기본 배송지가 된다. 기본 배송지는 최대 하나다.
- 기본 배송지를 삭제하면 가장 최근 등록한 남은 배송지로 변경한다. 모두 삭제하면 기본 배송지 없이 둔다.
- 회원 배송지를 수정·삭제해도 이미 생성한 주문의 배송지는 바뀌지 않는다.
- 실제 배송 연동과 결제 후 배송지 변경 서비스는 MVP에서 제외한다. 주문의 주소를 바꾸려면 미확정 범위에서 기존 주문을 취소하고 다시 주문하는 원칙을 따른다.
- 상세주소의 입력·표현 방식 등 기존 명세 차이는 구현 문서에서 정리할 사항이며 여기서 임의의 필수값을 만들지 않는다.

<a id="coupon"></a>
### 2.9 쿠폰

관련 기존 정책: CPN-001~007.

- 상품별 쿠폰만 제공한다. 주문 전체 쿠폰은 제외한다. 특정 상품 쿠폰 또는 카테고리 쿠폰을 주문상품 하나에 적용한다.
- 카테고리 쿠폰은 지정 카테고리와 모든 하위 카테고리에 속한 상품에 사용할 수 있다. 여러 카테고리에 해당해도 같은 금액을 중복 계산하지 않는다.
- 한 주문상품에는 쿠폰 한 장만 사용한다. 다른 주문상품에는 별도의 쿠폰을 사용할 수 있다. 소유한 쿠폰 한 장을 여러 상품에 중복 사용하지 않는다.
- 동일 쿠폰은 회원당 한 번, 한 장 발급한다. 사용·만료 뒤 재발급하지 않는다. 취소 시 기존 쿠폰 복구와 서비스 사유의 보상은 예외다.
- 발급 시 해당 쿠폰의 발급 대상·기간·기존 발급 여부를 확인한다. 할인액·할인율·상한·대상·유효기간은 쿠폰별 안내 조건을 사용한다. 새 가입 혜택도 과거 지급 이력 제한을 따른다.
- 최소 구매금액은 쿠폰별로 설정하며 0원이면 조건 없음이다. 특정 상품 쿠폰도 최소금액을 설정할 수 있다.
- 최소금액 판단은 해당 주문상품의 상품 자체 할인 후 단가 × 수량이며 쿠폰·포인트 차감 전이다. 다른 상품과 배송비는 포함하지 않는다.
- 정액은 해당 금액, 정률은 대상 금액 × 할인율로 계산한다. 정률의 1원 미만은 주문상품 합계에서 한 번 버린다. 쿠폰별 최대 할인액과 적용 상품 금액을 초과하여 할인하지 않는다. 미사용 할인액은 소멸하며 현금 반환하지 않는다.
- 쿠폰별 종료일시를 지정한다. 발급일에 따라 종료일이 연장되지 않는다. 이미 발급한 쿠폰의 조건은 소급 변경하지 않는다.
- 결제 대기 중에도 원래 종료일시가 적용된다. 결제 전에 만료되면 더 이상 사용할 수 없고 변경된 금액을 확인해야 한다.

<a id="point"></a>
### 2.10 포인트

관련 기존 정책: PNT-001~005, MON-001.

| 구분 | 확정 규칙 |
|---|---|
| 가치 | 결제 시 1포인트 = 1원 |
| 사용 단위 | 사용 총액은 10포인트 단위. 상품·수량별 배분 및 반환은 1포인트 단위 |
| 사용 한도 | 사용 가능한 잔액과 쿠폰 차감 후 구매금액을 초과하지 않는 10포인트 배수 |
| 전액 사용 | 금액이 사용 단위에 맞고 잔액이 충분하면 가능. 끝자리 1~9원은 일반 결제금액으로 남는다. |
| 적용 순서 | 상품 자체 할인 → 쿠폰 → 포인트 |
| 구매 적립 | 구매확정한 주문상품의 최종 일반 결제금액 합계의 1%, 1포인트 미만 버림 |
| 적립 제외 | 쿠폰 할인액·포인트 사용액·취소된 금액·부족분 납부액 |
| 후기 적립 | 조건을 충족한 후기 최초 등록 즉시 100포인트 |
| 유효기간 | 각 적립일부터 1년 |
| 사용 순서 | 만료가 가까운 유효 포인트부터 사용 |
| 만료 안내 | 7일 전 1회, 같은 날 만료되는 포인트는 합산하여 안내 |
| 취소 반환 | 원래 배분액 중 반환 완료 시 유효한 부분만 원래 만료일까지 사용 가능하게 복구 |
| 일반 만료 | 유효기간이 지난 미사용분은 소멸하며 취소로 새 기간을 부여하지 않음 |

구매 적립 계산 단위는 최신 선택인 **구매확정 주문상품 합계**다. 이전 ‘단품마다 버림’은 적용하지 않는다. 같은 주문상품은 남은 수량을 함께 확정하므로 확정 버튼을 나눠 누르는 방식으로 적립액이 달라지지 않는다.

포인트는 무상 보상이며 일반 충전·현금 출금·양도는 제공하지 않는다. 구매·후기 외 이벤트별 추가 적립은 현재 범위에서 운영하지 않는다. 블록체인 토큰은 이 포인트의 구현 방법이나 다른 명칭이 아니다.

후기 삭제 시 사용·만료 여부와 관계없이 그 후기로 지급한 100포인트를 한 번 회수한다. 이미 만료되어 이익이 사라진 경우도 회수한다는 명시적 사용자 선택이다. 부족하면 음수 잔액을 표시한다. 잔액이 양수가 되기 전에는 사용할 수 없으며 이후 적립 또는 반환액은 잔액에 반영되어 부족분을 먼저 충당한다. 상품 구매는 일반 결제와 쿠폰으로 계속할 수 있다.

음수 잔액 때문에 새 상품을 구매하도록 강제하지 않는다. 탈퇴 희망자는 이후 적립 또는 부족분 별도 납부로 0 이상을 만든다. 보상 지급·만료·회수의 원인이 달라도 같은 사유의 금액을 반복 지급·반환·회수하지 않는다.

<a id="review"></a>
### 2.11 후기

관련 기존 정책: REV-001~004, ORD-005, PNT-003.

- 구매확정한 본인의 주문상품에만 작성할 수 있다. 전량 취소한 주문상품에는 작성할 수 없다.
- 동일 주문상품은 수량과 관계없이 후기 최대 한 개다. 별도 주문으로 재구매하여 구매확정하면 새 후기와 새 보상을 받을 수 있다.
- 내용은 앞뒤 공백 제거 후 20~500자, 평점은 0.5~5.0점의 0.5점 단위로 필수다. 공백만 있는 글은 허용하지 않는다.
- 텍스트 후기만 지원하며 사진 후기는 제외한다. 사진 보상량을 별도로 만들지 않는다.
- 최초 작성·수정은 별도 기한 없이 허용한다. 내용·평점을 수정할 수 있고 수정 보상은 없다.
- 삭제는 가능하지만 같은 주문상품에 다시 작성할 수 없다. 삭제 전 재작성 불가·100포인트 회수·예상 잔액을 안내한다.
- 구매확정·중복 여부·글자 수·평점 조건을 자동 확인한 뒤 등록 즉시 100포인트를 지급한다. 일반 등록에 사전 운영자 승인은 요구하지 않는다.
- 욕설·광고·개인정보 노출 등 위반 후기는 운영자가 위반을 확인한 뒤 삭제하고 보상을 회수한다. 확인 전에는 공개를 유지한다. 이를 자동 숨김 정책으로 바꾸어 쓰지 않는다.
- 삭제된 후기는 후기 수·평균 평점에서 제외한다. 평점 수정은 집계에 반영한다. 후기가 없는 상품을 실제 0점 평가를 받은 것처럼 표현하지 않는다.
- 스포일러로 표시한 내용은 펼쳐보기 전 숨긴다.
- 최종 탈퇴 후에도 후기·평점은 유지하되 작성자는 ‘탈퇴 회원’으로 표시한다. 탈퇴 전 직접 삭제할 수 있음을 안내한다. 후기 본문에 포함된 개인정보는 표시명 제거만으로 익명화되었다고 보지 않는다.

### 2.12 알림

관련 기존 정책: NTF-001~002.

- 서비스 내 알림 대상은 결제 완료, 취소·환불 완료, 자동 구매확정, 자동확정 1일 전, 포인트 적립, 포인트 만료 7일 전이다.
- 해당 거래·혜택의 소유 회원에게 안내하며 같은 사건의 중복 알림으로 오인되지 않도록 한다. 읽기 전후를 구분하고 다시 읽었다고 새 알림이 되지 않는다.
- 읽음 여부와 관계없이 발생일부터 90일 후 삭제한다. 최종 탈퇴 시 먼저 삭제한다.
- 쿠폰 발급·만료 알림, 재입고 구독, 알림 종류별 설정과 외부 메시지 채널은 현재 제공 목록에 추가하지 않는다.

## 3. 주문부터 구매확정까지

1. 소셜 가입과 필수 온보딩을 완료한다.
2. 현재 가격·판매 가능 여부를 확인하고 장바구니에서 구매할 상품과 수량을 선택한다.
3. 주문을 생성하여 단가·선택 혜택·금액을 확인한다. 주문 유효기간은 15분이다.
4. 유효한 쿠폰·포인트와 구매 가능 여부를 확인하고 결제한다. 실패·중단하면 혜택 사용 제한을 해제하고 기한 내 재검증하여 다시 결제할 수 있다.
5. 결제가 완료되면 장바구니에서 구매 수량을 제거하고 구매확정 예정일을 안내한다.
6. 구매확정 전에는 일부 상품·수량 취소가 가능하다. 포인트는 원래 배분액, 쿠폰은 남은 수량의 조건을 기준으로 계산한다.
7. 사용자가 남은 주문상품을 직접 확정하거나 결제 후 7일에 자동확정한다. 해당 상품 취소 처리 중에는 확정을 보류한다.
8. 구매확정 시 일반 결제금액의 1%를 적립하고 후기 작성 자격을 부여한다. 이후 해당 상품 취소·환불은 MVP에서 제공하지 않는다.

<a id="money"></a>
## 4. 금액 계산과 검산 사례

### 4.1 금액 보존 원칙

**일반 결제금액 = 상품 자체 할인을 반영한 구매금액 − 쿠폰 할인 − 사용 포인트.** 배송비는 0원이다.

- 포인트는 쿠폰 적용 후 상품 금액 비율로 주문상품에 배분한다. 각 배분액의 1포인트 미만을 버린 뒤 남은 포인트를 버린 소수 부분이 큰 상품부터 1포인트씩 더한다. 동률은 주문 당시 상품 순서로 정한다.
- 상품별 적용 가능 금액을 넘지 않고 합계는 사용 총액과 정확히 같아야 한다. 같은 주문 조건·순서라면 결과도 같다.
- 같은 상품의 일부 수량 취소를 위해 수량별 배분도 주문 당시 확정한다. 동일 단가 수량은 균등 비율로 배분하며 동일한 잔여 배분 원칙을 적용한다. 이후 취소 시 남은 수량으로 포인트를 재배분하지 않는다.
- 쿠폰의 최초 할인 배분은 적용 주문상품 내부 수량에만 한정한다. 다만 부분취소 때 남은 상품에 적용할 쿠폰 할인은 원래 조건으로 재계산하므로 최초 할인 배분을 그대로 고정하는 포인트와 다르다.
- 배분 금액은 가치 추적 기준이다. 반환 시 만료된 포인트는 소멸 규칙을 따르므로 ‘배분액 반환’이 유효기간 연장을 뜻하지 않는다.

### 4.2 정상 거래와 상품별 포인트 배분

가정: 아래 금액은 상품 자체 할인·쿠폰 적용 후 금액이고 별도 배송비는 없다. 10,500포인트를 사용한다.

| 상품 | 금액 | 비율 | 포인트 배분 | 일반 결제 |
|---|---:|---:|---:|---:|
| A | 30,000원 | 20% | 2,100 | 27,900원 |
| B | 50,000원 | 33⅓% | 3,500 | 46,500원 |
| C | 70,000원 | 46⅔% | 4,900 | 65,100원 |
| 합계 | 150,000원 | 100% | 10,500 | 139,500원 |

B를 전량 취소하면 유효 포인트 3,500과 일반 결제 46,500원을 반환한다. 남은 일반 결제는 93,000원, 사용 포인트는 7,000이다. 이후 A·C도 모두 취소하면 일반 결제 총 139,500원과 유효 포인트 총 10,500을 반환한다.

### 4.3 10포인트 사용과 1포인트 잔여 배분

가정: 쿠폰 적용 후 상품 금액이 A 101원, B 102원, C 103원이며 사용 포인트는 10이다.

| 상품 | 정확한 비례 배분(근삿값) | 버림 | 최종 배분 | 남은 일반 결제 |
|---|---:|---:|---:|---:|
| A | 3.30065 | 3 | 3 | 98원 |
| B | 3.33333 | 3 | 3 | 99원 |
| C | 3.36601 | 3 | 4 | 99원 |
| 합계 | 10 | 9 | 10 | 296원 |

잔여 1포인트는 C에 배분한다. C 취소 시 4포인트를 반환할 수 있으며 이는 사용 총액의 10포인트 단위와 충돌하지 않는다. A·B·C가 모두 100원이면 소수 부분도 같으므로 주문 순서상 A에 1포인트를 더해 4·3·3으로 배분한다.

같은 상품 3개에 총 10포인트가 배분되었다면 수량별 4·3·3으로 정한다. 첫 수량 취소 시 4를 반환하고 남은 6을 재배분하지 않는다. 선택 가능한 동일 수량을 구분할 필요가 있을 때는 주문 당시 수량 순서를 유지한다.

### 4.4 쿠폰 조건 미달과 반복 취소

가정: 같은 책 2권이 각 30,000원, ‘50,000원 이상 5,000원 할인’ 쿠폰, 10,000포인트 사용. 최초 일반 결제는 **60,000 − 5,000 − 10,000 = 45,000원**이다. 포인트는 각 수량에 5,000씩 배분된다.

1권 취소 후 남은 30,000원은 쿠폰 조건을 충족하지 못한다. 남은 상품에 필요한 일반 결제는 **30,000 − 0 − 5,000 = 25,000원**이다.

| 처리 | 일반 결제 환불 | 포인트 반환 | 남은 일반 결제 | 남은 사용 포인트 |
|---|---:|---:|---:|---:|
| 첫 1권 취소 | 20,000원 | 5,000 | 25,000원 | 5,000 |
| 남은 1권도 취소 | 25,000원 | 5,000 | 0원 | 0 |
| 총 반환 | 45,000원 | 10,000 | — | — |

첫 환불을 ‘최초 배분 일반 결제 22,500원에서 쿠폰 5,000원 전액 차감’으로 계산하면 안 된다. 남은 상품의 최종 부담액과 이미 반환한 금액을 함께 계산해야 할인 회수가 중복되지 않는다.

취소 일반 결제액은 **취소 전 남아 있는 일반 결제액 − 취소 후 남은 상품에 필요한 일반 결제액**으로 계산한다. 쿠폰 조건을 유지하는 경우도 남은 금액에 정액·정률·최대 한도를 다시 적용한다. 전량 취소 시 남은 상품 부담은 0원이다.

### 4.5 환불 가능액을 넘는 할인 회수

가정: 같은 책 2권이 각 30,000원, 최소 50,000원에 40,000원을 할인하는 쿠폰, 포인트 사용 없음. 최초 일반 결제는 20,000원이다.

1권만 남기면 조건 미달로 남은 상품 부담은 30,000원이 되어 환불 계산이 **20,000 − 30,000 = −10,000원**이다. 이 부분취소는 제한하고 전체취소를 안내한다. 전체취소하면 최초 일반 결제 20,000원을 환불한다. 이 쿠폰 액수는 한도 정책을 설명하기 위한 가정이며 실제 발급값이 아니다.

### 4.6 정액 쿠폰 유지와 포인트 한도 충돌

가정: 같은 책 2권이 각 30,000원, 최소금액 조건 없는 정액 쿠폰 20,000원, 40,000포인트 사용으로 일반 결제는 0원이다. 포인트는 각 권에 20,000씩 배분된다.

1권 취소 후에도 정액 할인 20,000원을 유지하면 남은 책의 쿠폰 차감 후 금액은 10,000원인데 유지할 포인트는 20,000이다. 남은 일반 결제액이 −10,000원이 되어 결제하지 않은 현금을 반환하는 모순이 생긴다. 포인트를 임의 재배분하거나 추가 현금 환불하지 않고 해당 부분취소를 제한하여 전체취소를 안내한다. 이는 기존 금액 상한·고정 배분 원칙에서 도출하고 후속 보강 요청으로 채택한 부분취소 제한이다. 실제 행사 금액의 결정은 아니다.

### 4.7 만료 포인트 반환

가정: 취소 수량에 3,500포인트가 배분되었고 그중 1,000은 취소 완료 전에 만료, 2,500은 유효하다. **2,500만 원래 만료일로 복구**하고 1,000은 복구하지 않는다. 현금으로 대신 환불하지 않는다. 서비스 사유의 결제 실패 보상은 일반적인 구매 취소와 다른 예외다.

### 4.8 구매·후기 적립과 음수 잔액

- 구매확정한 주문상품의 일반 결제 합계가 25,000원이면 250포인트를 지급한다.
- 같은 상품 2개의 일반 결제 합계가 300원이면 1%인 3포인트다. 단품 150원마다 버려 총 2로 계산하지 않는다.
- 후기 보상 100 지급 후 80을 사용해 잔액이 20이면 후기 삭제 시 100을 회수하여 −80이 된다. 이후 100이 적립되면 잔액은 20이다.
- 후기 보상 100을 사용하지 않고 모두 만료시켜 잔액이 0이 되어도, 이후 후기 삭제 시 명시적 정책에 따라 −100이 된다. 삭제 전에 이를 안내한다.
- 같은 후기 삭제 요청이 반복되어도 같은 보상 100을 다시 회수하지 않는다. 탈퇴 전 부족분 납부는 부족분까지만 허용하며 초과 충전·추가 적립을 발생시키지 않는다.

## 5. 예외 처리와 사용자 안내

<a id="benefit-exception"></a>
### 5.1 결제 실패와 만료 혜택 보상

- 명확한 실패 시 유효한 쿠폰·포인트는 다시 사용할 수 있게 한다. 사용자 중단도 유효기간을 늘리지 않는다.
- 실패 시 이미 만료됐다면 원칙적으로 복구하지 않는다.
- **시도 당시에는 유효했으나 서비스 측 사유로 결제를 마치지 못하는 동안 만료된 경우**에만 같은 가치·사용 조건의 혜택을 보상 지급일부터 7일간 제공한다. 원래 만료일 자체를 일괄 연장하는 정책이 아니다.
- 사용자 사유의 실패·중단에는 보상하지 않는다. 동일 손실에 중복 보상하지 않고, 나중에 결제 완료가 확인되어 이미 혜택을 사용한 경우와 중복 인정하지 않는다.
- 보상 대상의 판단은 ‘당시 유효함·서비스 측 사유·그 사이 만료·미사용 손실’이 확인되는 경우다. 외부 서비스 내부 원인이나 비공개 판단 기준을 추정해 사실로 쓰지 않는다.
- 외부 PG 장애 분류·승인 확인·통신 재시도 등은 별도의 구현·운영 설계 범위다.

### 5.2 필수 안내

| 상황 | 사용자에게 안내할 내용 |
|---|---|
| 재결제 | 주문의 남은 기한, 만료·사용 불가 혜택, 변경된 최종 금액 |
| 부분취소 | 일반 결제 환불액, 반환 포인트, 만료로 복구하지 않는 부분, 쿠폰 재계산 결과 |
| 부분취소 제한 | 할인 회수로 추가 부담이 필요함과 해당 상품 전체취소 선택지 |
| 구매확정 | 확정 대상 남은 수량, 이후 취소 불가, 자동확정 예정일 |
| 후기 삭제 | 재작성 불가, 회수 보상액, 만료된 보상도 차감한다는 점과 예상 잔액 |

| 서비스 사유 보상 | 대상 혜택·조건·7일 사용 기한과 중복 보상 불가 |

## 6. 정보 보존·파기

관련 기존 정책: RET-001, USR-003, NTF-002.

다음은 **실제 금전 거래가 없는 테스트 MVP에 대해 사용자가 선택한 운영 정책**이다. 보존기간을 정했다는 사실만으로 개인정보 처리의 적법한 근거가 확보되는 것은 아니다. 처리 목적·항목·기간을 안내하고 필요한 처리 근거를 갖추어 적용한다. 법률상 보존이 필요한 실제 거래는 아래 테스트 파기 규칙의 대상에서 제외한다.

| 대상 | 보존·삭제 기준 | 사용 목적·제한 |
|---|---|---|
| 계정·일반 프로필·회원 배송지 | 회원 이용 및 탈퇴 취소 7일간 유지, 탈퇴 완료 시 파기 | 탈퇴 취소와 계정 이용. 별도 목적의 무기한 보존 금지 |
| 온보딩 답변·개인화 정보 | 회원 이용 중 유지, 탈퇴 완료 시 삭제 | 기존 회원의 추천 제공 |
| 추천용 행동 기록 | 발생일부터 90일, 탈퇴 완료 시 먼저 삭제 | 최근 이용에 기반한 추천 |
| 서비스 내 알림 | 발생일부터 90일, 읽음 여부 무관. 탈퇴 완료 시 먼저 삭제 | 거래·혜택 안내 |
| 개인 식별 가능한 테스트 주문·결제·취소·포인트 내역 | 탈퇴 완료 시 파기 | 이후에는 재식별할 수 없는 통계만 유지. 이전 계정 거래를 재가입 계정에 연결하지 않음 |
| 신규 혜택 수령 이력 | 최종 탈퇴일부터 1년 뒤 파기 | 이메일 기준 중복 지급 방지에 필요한 최소 이력만 보존. 마케팅·추천에 사용하지 않음 |
| 후기·평점 | 탈퇴 후 유지, 작성자 표시는 제거 | 작성자를 ‘탈퇴 회원’으로 표시. 회원과 거래의 식별 연결을 남겨 익명 통계라고 부르지 않음 |
| 실제 거래에 법정 보존 의무가 있는 기록 | 해당 법률상 대상·기산점·기간 적용 | 다른 목적에 재사용하지 않고 별도 관리. 테스트 기록에 일괄 5년 적용하지 않음 |

혜택 이력 보존 종료 뒤 과거 수령 여부를 판별하지 않는다. 동일 이메일 신규 혜택을 ‘평생 한 번만’ 보장한다고 표현하지 않는다. 탈퇴 완료 후 재가입은 허용하되 보존 중인 수령 이력이 있으면 지급하지 않는다.

후기 본문에 이름·연락처 등 식별 정보가 있으면 ‘탈퇴 회원’ 표시만으로 익명화되지 않는다. 공개 후기의 개인정보 노출은 위반 후기 처리 정책을 적용한다. 재식별 가능한 원본을 단순히 통계라는 이름으로 남기지 않는다.

실제 전자상거래의 계약·청약철회·결제 등 기록 보존과 테스트 운영기간은 구분한다. 공개 법령 안내는 계약·청약철회 및 대금결제·공급 기록 5년, 소비자 불만·분쟁 기록 3년, 표시·광고 기록 6개월을 설명한다. 실제 판매·수납 전환 시 해당 거래의 적용 여부와 개인정보 처리 근거를 검토해야 하며 이 위키는 실제 운영 약관의 법률 검토를 대체하지 않는다. [공식 거래기록 안내](https://www.easylaw.go.kr/CSP/CnpClsMainBtr.laf?ccfNo=3&cciNo=3&cnpClsNo=1&csmSeq=25&menuType=cnpcls&popMenu=ov), [개인정보 파기 원칙](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1027063705)

### 6.1 개인정보 처리 근거와 적용 조건

**운영 정책의 기간 결정과 법적 처리 근거 확인은 별개의 작업이다.** 아래는 적용할 근거의 검토 기준이며, 실제 동의서·서비스 계약·처리 상황을 확인하지 않은 상태에서 적법성 검토가 끝났다고 표시하지 않는다.

| 처리 목적 | 검토할 근거 | 적용 조건 |
|---|---|---|
| 계정·본인 거래·배송지 등 요청한 서비스 제공 | 계약 이행 또는 계약 체결 과정에서 사용자가 요청한 조치에 필요한 처리 | 실제 필요한 최소 항목만 취급한다. 계약과 무관한 수집까지 이 근거로 확대하지 않는다. |
| 온보딩·추천용 행동 기록 | 요청한 개인화 서비스에 필요한 범위 또는 별도 동의 | 온보딩이 필수라는 서비스 결정만으로 모든 행동 추적이 필수 개인정보가 되지는 않는다 ² |
| 탈퇴 후 신규 혜택 중복 방지 | 별도 동의 또는 정당한 이익 요건을 충족하는 처리 | 단순 약관 고지만으로 충분하다고 보지 않는다 ³ |
| 실제 거래의 법정 기록 보존 | 해당 법령상 보존 의무 | 의무 대상 기록·기간·기산점을 특정하고 다른 서비스 데이터와 구분한다. |
| 탈퇴 후 후기 공개 | 후기 이용 조건 및 남아 있는 개인정보의 처리 근거 | 표시명 삭제만으로 개인정보가 없어졌다고 판단하지 않는다. 본문·회원 연결을 함께 확인한다. |

² 항목별 필요성과 동의 필요 여부를 확인한다.
³ 정당한 이익을 쓰려면 목적·필요성·이용자 권리와의 비교를 문서로 검토한다.

동의에 근거할 때는 목적, 항목, 보유·이용 기간, 동의 거부권과 실제 불이익을 안내한다. 계약 이행에 필요한 처리와 별도 동의가 필요한 처리를 구분한다. **처리 근거가 확보되지 않은 항목은 보존 정책에 적혀 있다는 이유만으로 수집·유지하지 않는다.** 그 경우 1년 중복 방지 기능도 적법하게 확인 가능한 범위에서만 제공한다.

신규 혜택 이력의 최소 범위는 동일 이메일 판별에 필요한 정보, 어떤 신규 혜택을 받았는지와 지급일, 보존 종료를 판단할 탈퇴 완료일이다. 전체 주문·주소·온보딩 답변을 붙여 보존하지 않는다. 이메일을 다른 형태로 바꿨더라도 같은 사람을 구별할 수 있다면 익명 정보로 단정하지 않는다.

이 절은 적용 전 확인 항목을 구체화한 것이며 별도의 법률 검토 완료 인증이 아니다. 소셜 제공자의 이메일 전달 동의가 우리 서비스의 탈퇴 후 장기 보존 동의를 자동으로 대신하지 않는다. [개인정보 보호법 제15조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334745), [개인정보 보호법](https://www.law.go.kr/lsInfoP.do?ancYnChk=0&lsId=011357)

### 6.3 공개 전 점검표 — 개인정보 문안은 내부 검토 초안

**검토 상태: 내부 문안 초안. 그대로 게시하거나 동의를 수집할 완성본이 아니다.** 2026-09-09 작업 폴더에서 확인한 파일은 정책 위키와 기존 검토 초안뿐이다. 실제 회원가입 화면, 개인정보 처리방침, 소셜 동의 화면, 이용약관, 위탁 계약은 제공되지 않았다. 아래 대조는 합의한 정책과 작성 문안 사이의 대조이며 배포된 서비스의 준법성 검증이 아니다.

#### 가. 서비스 조건에 넣을 안내 문안

> 북적북적은 현재 테스트 결제 기반 MVP입니다. 실제 배송과 블록체인 화폐·토큰은 제공하지 않습니다. 회원은 온보딩을 완료한 뒤 서비스를 이용할 수 있습니다. 결제 완료 후 7일이 지나면 주문상품의 남은 수량이 자동 구매확정되며, 그 전에 직접 확정할 수도 있습니다. 구매확정 후 취소·환불은 이 테스트 MVP에서 제공하지 않습니다.
>
> 포인트는 구매확정 시 일반 결제금액의 1%, 후기 최초 등록 시 100포인트를 지급하며 적립일부터 1년간 사용할 수 있습니다. 후기 삭제 시에는 이미 사용하거나 만료된 보상도 전액 회수하여 잔액이 음수가 될 수 있습니다. 음수 잔액은 이후 적립 또는 부족분만 별도로 납부하여 해소할 수 있습니다. 포인트의 일반 충전·현금 출금·양도는 제공하지 않습니다.
>
> 탈퇴하려면 진행 중 거래와 포인트 부족분을 먼저 해소해야 합니다. 신청 후 7일 이내 다시 로그인하면 탈퇴를 취소할 수 있습니다. 그동안 혜택의 유효기간은 연장되지 않습니다. 탈퇴 완료 후 재가입은 가능하지만 보존 중인 이메일 기준 신규 혜택 수령 이력이 있으면 같은 혜택을 다시 지급하지 않습니다. 해당 이력은 탈퇴 완료 후 1년까지 보존합니다.
>
> 작성한 후기는 탈퇴 후에도 ‘탈퇴 회원’으로 표시하여 유지됩니다. 원하지 않는 후기는 탈퇴 전에 삭제할 수 있으며 삭제한 후기는 같은 주문상품에 다시 작성할 수 없습니다. 개인정보의 삭제·처리정지 등 법률상 권리 행사 요청은 일반 후기 수정·재작성 제한과 별도로 처리합니다.

이 문안은 합의된 서비스 조건 요약이다. ‘7일 내 일반 탈퇴 취소’ 안내가 개인정보 동의 철회나 삭제 요청을 7일 동안 일률적으로 거절하는 근거가 되지 않는다. 테스트 부족분 납부를 실제 수납으로 전환할 때는 수납 사실과 법정 기록 보존 등 달라지는 조건을 먼저 반영한다.

| 추천 행동 분석 | **[실제로 수집하는 행동 종류 확인 필요]** | 발생일부터 90일 또는 탈퇴 완료 중 먼저 도래하는 때 | 선택 분석 동의 또는 계약상 필요성 판단 전. 기기·접속·위치 정보를 관행적으로 추가하지 않음 |
| 서비스 내 알림 | 수신 회원, 알림 내용·발생일·읽음 여부 | 발생일부터 90일 또는 탈퇴 완료 중 먼저 도래하는 때 | 요청한 거래·혜택 알림 제공 목적. 광고 수신 동의와 혼합하지 않음 |
| 신규 혜택 중복 방지 | 이메일 판별 정보, 혜택 종류·지급일, 최종 탈퇴일 | 회원 이용 중 및 최종 탈퇴 후 1년 | 아래 별도 동의안 또는 정당한 이익 검토 중 실제 근거 확정 필요 |
| 공개 후기 유지 | 후기 내용·평점, 탈퇴 후 비식별 작성자 표시 | 삭제 전까지 공개 유지 | 본문 개인정보·계정 연결 확인 필요. 표시명 변경만으로 익명화 완료 아님 |

위 표는 ‘실제로 수집한다’는 사실 목록이 아니다. 구현 전 단계의 최소 범위 초안이며 실제 입력 화면·소셜 응답·외부 제공 내역을 대조해 확정한다. 수집하지 않는 항목은 게시 문안에서도 제거한다.

#### 다. 신규 혜택 이력 별도 동의안 — 선택 시에만 사용

이 문안은 **별도 동의 방식을 채택할 경우의 초안**이다. 아직 운영 방식을 임의로 확정하지 않는다. 동의와 정당한 이익을 동시에 나열해 거부·철회를 무력화하지 않는다.

> **신규 가입 혜택 중복 지급 방지를 위한 개인정보 수집·이용 안내**
>
> - 목적: 같은 이메일로 신규 가입 혜택을 반복 지급받는 것을 방지합니다.
> - 항목: 동일 이메일 판별에 필요한 정보, 신규 혜택 종류와 지급일, 최종 탈퇴 완료일입니다.
> - 기간: 회원 이용 중 및 최종 탈퇴 완료일부터 1년입니다. 기간이 끝나면 파기합니다.
> - 이용 제한: 이 정보는 마케팅이나 취향 추천에 사용하지 않습니다.
> - 거부·철회: 동의를 거부하거나 철회할 수 있습니다. 가입·일반 서비스 이용을 선택 동의 거부만으로 제한하지 않습니다. 신규 혜택 제공에 미치는 영향은 **[실제 제공 조건 확정 후 명시]**합니다.
> - 문의·권리 행사: **[실제 문의 창구 입력]**로 요청할 수 있습니다.

혜택 제공 조건과 거부 불이익을 빈칸으로 둔 채 동의를 받지 않는다. 철회가 있으면 다른 적법한 보존 근거가 없는 한 해당 처리 중단·파기를 검토하고, 이력 삭제 뒤에는 동일 이메일의 과거 지급을 완전히 판별할 수 없다는 한계를 인정한다. 탈퇴를 했다는 사실만으로 기존 동의가 언제까지나 유지된다고 보지 않는다.

정당한 이익에 근거하려면 단순히 ‘부정 이용 방지’라고 쓰는 것으로 끝내지 않는다. 실제 중복 지급 위험, 보존 항목의 최소성, 1년 필요성, 덜 침해적인 대안, 이용자의 예상·권리 영향과 보호조치를 비교해야 한다. 현재는 이 증거가 없어 **정당한 이익 요건 충족을 확인하지 못했다**.

#### 라. 권리 행사 안내 문안 초안

> 개인정보의 열람·정정·삭제·처리정지 또는 동의 철회는 **[개인정보 문의 창구]**로 요청할 수 있습니다. 요청자 확인에 필요한 최소 정보로 확인하며, 법률상 보존이 필요한 기록은 그 근거와 범위를 설명합니다. 단순 회원 탈퇴와 개인정보 권리 행사 요청을 동일하게 취급하지 않습니다. 처리 후에는 처리 결과를 안내합니다.

문의 창구는 최종 탈퇴 후에도 사용할 수 있어야 한다. ‘포인트가 음수이므로 모든 개인정보 권리 행사를 거부한다’는 문구를 두지 않는다. 적립금 정산과 개인정보 관련 요청에 적용되는 기준은 구분한다.
